## 🚀 Projects

### 1. 📚 Quizzon — Quiz App

> *A fun and interactive quiz app with real-time scoring and a clean UI*

Quizzon is a polished Android quiz application that tests your knowledge across multiple categories with smooth navigation and instant feedback.

#### ✨ Features

- 🗂️ Multiple quiz categories
- ⚡ Real-time score tracking
- 🎨 Clean and modern UI
- 🔄 Fast & smooth performance
- 🧭 Beginner-friendly navigation

### 2. 🎨 DrawingApp — Canvas Drawing App

> *A native Android drawing application built on Canvas API*

A touch-based drawing app that lets users sketch freely on screen using Android's Canvas and Paint APIs.

#### ✨ Features

- 🖌️ Freehand drawing on touch canvas
- 🎨 Color selection
- Native Android Canvas & Paint API
